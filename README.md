# Sticky Notes in Flutter 📝
A simple, elegant, and easy-to-use sticky notes app built with Flutter. Manage your notes efficiently with a clean interface and smooth interactions.

</br>

## Features
- Create, edit, and delete notes
- Save notes locally on your device
- Intuitive and responsive UI
- Light and dark themes support
- Seamless note management

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (version 3.0+ recommended)
- Dart SDK
- An IDE like Android Studio, VS Code, or any preferred editor

</br>

### Installation

## Clone the repository:
```sh
git clone https://github.com/sufyanism/Sticky-Notes-in-Flutter.git
```

## Navigate into the project directory:
```sh
`cd Sticky-Notes-in-Flutter`
```

## Install dependencies:
```sh
flutter pub get
```

</br>

## Running the App
To run on an emulator or connected device:
flutter run
